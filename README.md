# blox

Prototype du jeu Roblox **Chrono-Forge: La Ville qui Rembobine**.

## Démarrage (Roblox Studio)
1. Créer un nouveau projet dans Roblox Studio.
2. Copier le contenu de `src/` dans les services correspondants :
   - `ServerScriptService` ⟵ `src/Server/`
   - `StarterPlayerScripts` ⟵ `src/Client/`
   - `ReplicatedStorage` ⟵ `src/Shared/`
3. Lancer en mode Play.
